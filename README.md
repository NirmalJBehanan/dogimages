# 🐶 Dog Image Generator

A simple and fun web application that generates dog images based on HTTP status codes using the http.dog API.

## 📌 About The Project
Dog Image Generator allows users to enter an HTTP status code (100–599) and instantly view a matching dog-themed image related to that status code.

This project was built using:
- HTML5
- CSS3
- JavaScript
- http.dog API

## ✨ Features
- Generate dog images using HTTP status codes
- Simple and clean user interface
- Responsive design for mobile and desktop
- Input validation with min and max values
- Dynamic image rendering using JavaScript

## 🚀 How It Works
1. Enter any HTTP status code between **100 - 599**
2. Click **Generate Images**
3. The corresponding dog image will appear instantly

Example:
- 200 → Success Dog
- 404 → Not Found Dog
- 500 → Server Error Dog
